# THEVE // TACS-8 — Design Notes

## 1. 概念

**SUNSET SPEAR / 落日之矛** 是一个关于「黄昏、钢铁与最后一片自由空域」的视觉实验。
它不是把游戏 HUD 截图搬进网页，而是把第一人称空战的视觉语法拆成可复用的设计系统：

- **舱外**：橙金色落日、层叠云海、巨大的战争机器剪影。
- **舱内**：近黑金属框架、玻璃反光、青磷光航电、琥珀色锁定信号。
- **叙事**：CIRRUS 特遣队、LUMEN 1/2、SENTINEL 预警机、VESPER 敌军、LEVIATHAN 空中无畏舰。
- **产品**：所有图形、音效与代码原创；以 `@theve/ui` 交付，Showcase 验证它在真实交互中的表现。

温度差是核心：**外部世界暖而广阔，内部仪表冷而精确。** 所有 UI 面板都带深色 scrim，
保证压在亮天空和太阳上仍然可读；只有在关键行动点（锁定、告警、巨兽）才允许暖色越过 UI。

## 2. 色彩系统

| 语义 | Token | 值 | 使用 |
| --- | --- | --- | --- |
| 虚空 | `--tv-void` | `#04070C` | 座舱底、页面底 |
| 深舱 | `--tv-deep` | `#07131D` | 面板、菜单 |
| 玻璃 | `--tv-panel` | `rgba(8,22,32,.82)` | HUD 卡片 |
| 主信号 | `--tv-cyan` | `#63F3FF` | 主读数、可操作态、准星 |
| 冰白 | `--tv-ice` | `#E8F8FC` | 主要文字 |
| 次信号 | `--tv-cyan-dim` | `#2C8E9E` | 刻度、次级标签 |
| 沉默 | `--tv-mute` | `#86A3AE` | 说明文字 |
| 锁定 / 注意 | `--tv-amber` | `#FFB547` | 锁定完成、热焰弹、评分 |
| 敌意 / 告警 | `--tv-red` | `#FF4D5A` | 敌机、导弹、损伤 |
| 友军 | `--tv-green` | `#74FFB0` | 僚机、链接、正常状态 |
| 落日 | `--tv-sun` | `#FF7A3D` | 仅用于环境光与地平线 |

**使用纪律：**

1. 暖色不承担普通信息：红 = 威胁/失败，琥珀 = 锁定/注意，绿 = 友军/安全。
2. 颜色不是唯一编码：敌机用三角/方形/菱形、锁定用括号形状、告警用方向箭头。
3. 所有面板用深色底；没有纯色高亮大块，除了电影化的 boss / 告警条。
4. 文字对比度以 WCAG AA 为目标；HUD 数字额外加 1px 深色文字阴影。

## 3. 字体与排版

- Display：`Bahnschrift SemiCondensed` / `DIN Alternate` / `Arial Narrow`，大写、宽字距。
- Data：`Cascadia Mono` / `JetBrains Mono` / `Consolas`，`font-variant-numeric: tabular-nums`。
- 正文 / 中文：`Noto Sans SC` / `Microsoft YaHei UI` / `system-ui`。
- 不使用远程字体：离线可用，避免视觉闪烁和第三方请求。
- HUD 标签 6–9px，读数 15–22px，展示标题 32–178px；小字号依赖字重、字距与高对比来保持清晰。
- 中文叙事与英文航电标签并置，既是世界观，也是信息层级：英文负责“系统”，中文负责“人”。

## 4. 几何与材质

- **切角**：面板 / 按钮的 8–12px 斜切，模拟航电面板的冲压件。
- **括号**：`::before/::after` 绘制的 1px 四角括号，标记可交互区域。
- **刻度**：速度 / 高度 / 航向带，固定中心指针，刻度 ±范围滚动。
- **扫描线**：3–4px 的极低不透明度横向纹理；在“启动 / 告警 / boss”时才会加强。
- **颗粒 / 暗角**：给纯 CSS 的展示页与 3D 画面统一胶片感。
- **危险条纹**：45° 琥珀/黑条纹，仅用在简报底部、告警面板、警告芯片。

## 5. HUD 语言

三个层级：

1. **主 HUD（不遮挡视野）**：航向带、俯仰梯、速度/高度带、飞行路径标记、目标框、锁定菱形。
2. **战术卡（可读性优先）**：任务目标、分数、僚机、雷达、通讯、武器架、巨兽条。
3. **瞬时反馈**：导弹告警、损伤暗角、命中白光、击杀字幕、系统音。

布局遵循“中心留白、两侧读数、底部操作”的座舱逻辑：

- 中心只保留飞行路径标记、目标框和锁定菱形；告警放在偏左上方而不是正中，避免遮住 boss。
- 左侧：目标卡 → 速度带 → 雷达；右侧：分数 → 高度带 → 通讯 / 僚机；底部中央：实体控制台。
- 目标在屏幕外时会被钳制到边缘并带方向箭头，避免玩家失去态势。
- 非当前目标只画括号，不画完整标签；减少空战中的信息噪声。

## 6. three.js 座舱与战场

- **相机**：座舱相机跟随飞行器姿态，座舱框是相机子节点；世界用云海 / 天空 / 实体随姿态运动，
  形成真实的头部与机体分离感。
- **天空**：自定义 shader 的 3 段渐变 + 低角度太阳 + 地平线雾化；不使用贴图。
- **云海**：平面 FBM 噪声 + 近场 billboard 云团；时间/速度 uniforms 让云层流动。
- **座舱框**：低多边形 A 柱、顶弧、仪表台、仪表灯、铆钉、丝印贴图；相机近裁面 0.03。
- **实体**：低多边形战机（双色航行灯、尾焰、翼尖凝结尾迹）、巨型无畏舰（分层舰体、窗户光、
  旋转雷达、反应堆灯、护盾节点、边缘线框）。
- **目标投影**：每帧把实体世界坐标投影到屏幕，写入模拟快照；DOM HUD 用 `transform` 定位。
  目标离屏时计算屏幕边缘方向，不再让目标标记卡在画面中央。
- **性能**：不启用阴影地图；渲染循环与 React 分离；实体材质/几何在移除时释放；DPR 上限 1.7，
  画质自动降级；`prefers-reduced-motion` 关闭镜头抖动；WebGL 不可用时回退到 CSS 黄昏座舱。
- **武器反馈**：加色 sprite 爆炸、tracer 线、薄雾状冲击波；所有粒子受对象上限保护。
- **v0.3 打击层**：命中火花（加色、带重力与初速）、碎片（翻滚、受重力）、
  护盾涟漪（每帧朝向相机的细圆环）、炮口闪光、弹幕爆烟（**普通混合**的软烟贴图，
  加色混合会把烟画成发光的雾）。
- **v0.3 氛围层**：一盏 3 点的池化 `PointLight`，爆炸真的照亮云层；
  池子常驻场景（强度归零而不是 `visible = false`），因为增删光源会让 three.js
  在空战中途重编译所有材质。远景弹幕与曳光弹按阶段定时生成，
  只出现在前方 2.6–8.6 km，不参与任何判定。
- **v0.3 受创烟迹**：血线低于 55% 的飞机从 30 个精灵池里取烟，纯渲染层、
  不经过模拟、不增加场景子节点数量。
- **v0.3 镜头冲击**：命中、开火与受击各自给一个按临界阻尼弹簧衰减的旋转冲量
  （x=俯仰、y=偏航、z=滚转）。受击的冲量方向由来袭方位决定，从右边被打中就会向右偏。
- **v0.3 调色**：`intensity` 连续调节 `toneMappingExposure`、雾密度与半球光，
  平静时明亮温暖，激战时压暗、起雾、变冷。零额外 draw call。

## 7. 声音设计

### 7.1 分层

| 层 | 合成方法 | 触发 |
| --- | --- | --- |
| 引擎 | 双锯齿 + 噪声 + 低通 | 随油门/速度连续变化 |
| 风噪 | 带通噪声 | 随速度增加，减速板与机动再加一档 |
| 搜索 / 锁定 | 620→1050Hz 方波脉冲 → 1240Hz 稳态 | 随锁定进度爬升，锁定后转实音 |
| RWR | 660Hz 三角双音，速率随威胁提高 | 导弹接近 |
| 机炮 | 高通瞬态 + 96→48Hz 音体 + 机械方波 | 按住连射，每发轻微失谐 |
| 命中确认 | 2.1kHz 三角 + 五度正弦 + 金属噪声 | 只有**你**打中时才响；击坠时补一个三音上行 |
| 护盾跳弹 | 2.8kHz 带通 + 1500→360Hz 锯齿下滑 | 打在未破的护盾节点上 |
| 爆炸 | 高频爆裂 + 低通音体 + 正弦 sub + 碎片尾音 | 距离决定延迟、截止频率与音量 |
| 掠过 | 200→2600→420Hz 带通扫频 | 导弹进入 420 m，按真实声速延迟 |
| 配乐 | 见 7.2 | 全程 |
| 低机体告警 | 720–980Hz 方波双音，间隔随损伤缩短 | 机体低于 34% |

- 首次用户手势才创建 AudioContext；静音时不启动音频图。
- 总线压缩 / 限幅；主音量、静音持久化。
- **爆炸用距离说话**：`distance / 340` 秒的延迟是真实声速。远处弹幕因此先看到火光、
  后听到闷响，而且高频被削掉——这是把「画面里有一堵噪声墙」变成「一片有纵深的战场」最省力的办法。
- **电台压低配乐**：每条通讯把音乐总线压到 42%，持续约 1 秒，字幕永远读得清。
- 全部原创合成，无外部音频文件或采样。混响是用程序生成的脉冲响应（2.1 秒衰减噪声）喂给 `ConvolverNode`。

### 7.2 v0.3 配乐：一台编曲机

v0.1/v0.2 的「配乐」是四个和弦的 drone 加一个脉冲。v0.3 换成一台真正的编曲机，
写作在 D 自然小调上，全部数据与纯函数放在 `src/audio/score.ts`，可以被单元测试当成乐谱审阅，
只有 `AudioEngine` 负责发声。

**六个段落**（`SCORE_SECTIONS`）：

| Cue | BPM | 和声 | 配器意图 |
| --- | --- | --- | --- |
| 翱翔 `soar` | 62 | Dm · Bb · F · C | 只有弦乐、竖琴与一支长线条独奏，留出天空的宽度 |
| 制空 `dogfight` | 88 | Dm · Bb · F · C · Dm · Bb · Gm · Am | 行进鼓点 + 八分音符弦乐固定音型，旋律仍然可唱 |
| 强攻 `assault` | 100 | Dm · Bb · F · C · Dm · Gm · Bb · Am | 十六分音符固定音型、铜管重音、太鼓推进 |
| 巨兽 `boss` | 108 | Dm · Dm · Bb · Gm · F · C · Gm · Am | 低音铜管、合唱层、双踩太鼓，旋律升到最高音区 |
| 凯旋 `victory` | 84 | F · C · Dm · Bb · F · C · F · F | 相对大调的赞美诗进行，竖琴琶音收束，全曲唯一不带鼓的收尾 |
| 挽歌 `elegy` | 56 | Dm · Gm · Dm · Am | 稀疏、下行，只留低音弦乐与一支独奏 |

**十条写好的旋律**（`PHRASES`）。旋律不是随机音，而是十句可唱的乐句，
用相对主音的音级写出，因此在任何和弦上都能落得住：

- `theve` THEVE 动机（D–F–A–D′，上行，带滑音）、`dawn` 黎明、`arch` 拱形、`call` 呼唤、
  `resolve` 落定、`climb` 攀升、`soar` 翱翔、`storm` 风暴、`lament` 挽歌、`pedal` 持续音。

每个段落的 `programme` 为和声的每一小节指定一句，因此八小节的循环里会出现八句不同的旋律，
而不是同一句反复。**悠扬**来自长音、级进与偶尔的八度跳进，以及领奏声部上的滑音与迟到颤音；
**史诗**来自太鼓、低音铜管、合唱五度层与十六分音符固定音型的同时进入。

**时钟与换段**：小节按 `AudioContext.currentTime` 提前 0.85 秒排定（前瞻调度器），
所以无论帧率如何，pad、领奏与太鼓都锁在同一张网格上。换段只发生在小节线上，
且普通段落至少停留两小节；`victory` / `elegy` 作为终止态立即生效。
`boss-intro` 故意落在 `assault` 而不是 `boss`，这样进入巨兽段是一次上行而不是平移。

**驱动信号只有一个**：模拟每帧算出一个 0..1 的 `intensity`（威胁、过载、速度、损伤、连击、阶段），
配乐用它选段落，混音用它调密度，3D 用它调曝光与雾。三者读同一个数，所以画面、音乐与手感一起呼吸。

## 8. 动效

- 面板 220–420ms 切入；启动打字机 280ms/行；boss 条 letterbox 700ms；结算 rank stamp 650ms。
- 雷达扫描 4.4s，扫描线循环；告警 500ms 脉冲；锁定 800ms 心跳。
- 所有动效有静态降级：系统 `prefers-reduced-motion` 或设置中关闭。
- 3D 镜头有速度 buffet 与爆炸 shake，但仅在 reduced-motion 关闭时启用。
- **v0.3 打击反馈不是动画，是函数。** 模拟给每个瞬时事件打上 `age`，
  HUD 只把 `age` 换算成缩放与透明度：暂停时它们停在原地，掉帧也不会和那一枪错位，
  reduced-motion 下把缩放钉死为 1 即可。

## 11. v0.2 — 战机操作

这一版只动「手」和「眼前的一行字」，不动世界观、配色与叙事。

### 11.1 飞行手感

旧模型是三条互相独立的常量积分（滚转 1.95 rad/s、俯仰 0.98 rad/s、速度向油门目标逼近），
手感偏「滑」。v0.2 换成一组互相咬合的项：

| 层 | 做法 | 玩家感知 |
| --- | --- | --- |
| 操纵权限 | 所有轴乘以动压系数 `clamp(speed/245, .42, 1.28)` | 低速时杆变软，高速时杆变利 |
| 滚转 | 角加速度 13.4 + 阻尼 6.2，上限 3.7 rad/s | 机翼有重量，松杆后会继续滚一点 |
| 俯仰 | 一阶滞后（λ=8.2）追踪 1.06 rad/s 指令 | 拉杆有惯性，不会瞬间贴住包线 |
| 转弯 | `tan(bank)·g/V` 坡度升力 + 滚转协调舵 0.1·rollRate | 压坡度就能转，且不再侧滑 |
| 能量 | 油门速度 + 重力 `-sin(pitch)·46` − 诱导阻力 | 爬升掉速、俯冲增速，拉杆会掉速 |
| 过载 | 由俯仰角速度与速度实时积分，4.5 时间常数 | G 表跟着杆动，不再只看输入幅度 |
| 包线 | 失速地板 150 m/s，上限 330 m/s，姿态 ±77° | 不会失速坠机，也不会飞出天际 |

### 11.2 机动系统

两族：**持续型**（按住的 `C` / `X`）只是在操纵权限、转弯增益和阻力上叠系数，玩家始终握着杆；
**脚本型**（`Z V B N K`）由飞控按归一化时间 `t∈[0,1]` 的姿态目标曲线接管俯仰，滚转与偏航走角速度曲线。

脚本机动的三个关键设计：

1. **姿态目标而非角速度**：无论从什么姿态进入，出口姿态都可预测；结束时统一把
   `(yaw, pitch, roll)` 归一化回 `±77°` 包线（利用 `(yaw,π−pitch,roll+π)` 的等价性）。
2. **速度矢量解耦**：`velocityLock` 让位移方向在机动初期冻结在进入方向，这是眼镜蛇「机头先走、航迹不走」
   的关键；库尔比特用 0.62 的滞后跟随做出极小半径筋斗。
3. **限制进入条件**：速度 / 高度门槛 + 一次性机动不可打断，HUD 用灰色与原因文案说明为何不能起飞。

| 机动 | 剖面要点 | 甩弹概率 |
| --- | --- | --- |
| 眼镜蛇 | 0.34 段 easeInOut 抬到 +1.95 rad，保持到 0.6，再平滑回收 | 0.70 |
| 桶滚 | 恒定 `2π/1.35` rad/s 滚转 + `sin(2πt)` 侧向摆动 | 0.55 |
| 破S | 0→0.3 半滚 π，0.3→0.94 下扣 −π | 0.30 |
| 殷麦曼 | 0→0.68 半筋斗 +π，0.68→1 半滚 π | 0.20 |
| 库尔比特 | 0→0.88 easeInOut 完整 2π 筋斗 | 0.65 |

### 11.3 辅助驾驶

原则：**辅助只在你没有操作的那根轴上出力**，且永远不改变输入语义。
`freedom = 1 − clamp(|pilot| / deadzone, 0, 1)`，deadzone 取 0.26–0.4。

| 代号 | 算法 | 预算 |
| --- | --- | --- |
| `ATT` | 滚转速率阻尼 + 近中立（<0.22 rad）回正 | 滚转 0.40，阻尼 0.30 |
| `STG` | 对锁定目标的偏航 / 俯仰误差比例控制，±74° 外线性衰减 | 偏航 0.34，俯仰 0.26 |
| `THR` | 目标速度伺服，**只在 `pilotThrottle` 之上加**，1.6s 无输入后介入 | ≤0.9 油门/秒 |
| `ALT` | 1300/820/520 m 三级；越低越不理会玩家输入 | 俯仰 0.62 |

脚本机动进行时所有辅助让位（`maneuverActive`），因为那一刻飞控已经全权接管。

### 11.4 简要操作说明

进入任务后底部中央出现的 `StartupChecklist`：7 条、4 列、可勾选、可关闭。
它不是静态说明书——引擎用 `tutorialFlags` 记录玩家是否真的做过「俯仰+滚转 / 油门 / 切换目标 / 锁定 /
发射 / 机动 / 热焰弹」，做到就打勾；7/7 后停留 6 秒自动收起，30 秒未完成也收起，`H` 里还有完整手册。

### 11.5 版式取舍

- 机动与辅助的**状态**放在左侧导轨（`MODE` + `ASSIST` 灯 + G 表），避免和既有卡片抢位置。
- 机动与辅助的**操作**放在底部实体控制台（`MANOEUVRE` / `FLIGHT AIDS` 两个模块），
  这样触屏玩家也能按到；`≤1240px` 收窄列数，`≤1024px` 让位给武器与 FIRE。
- 机动横幅（`ManeuverBanner`）压在画面 27% 高度、只占一行，boss 条（132px）不会被遮住。
- 锁定引导杆（`LockSteeringCue`）画在准星下方 58px，只在「已选目标但未锁定」时出现。

## 12. v0.3 — 音效与打击感

这一版只动「耳朵」和「打中的那一瞬间」，不动世界观、配色与叙事骨架。
音频与打击感是同一件事的两半：**先让玩家知道打中了，再让他觉得爽。**

### 12.1 打击感的三层

打击感不是「多放粒子」，而是把一次命中拆成三个必须在同一帧里对上的信号：

| 层 | 手段 | 延迟预算 |
| --- | --- | --- |
| 听觉 | 金属短鸣（2.1kHz 三角 + 五度），只有玩家命中才响 | &lt; 20 ms |
| 视觉（准星） | 四道冰白刻线炸开 + 伤害数字 + 连击计数 | 同帧 |
| 视觉（世界） | 命中点的加色火花（带初速与重力）+ 机身爆炸光 | 同帧 |
| 触觉（伪） | 镜头冲量 + 轻微 shake | 同帧，120 ms 内衰减完 |

关键决定：**刻线用冰白而不是琥珀**。第一版用琥珀色画在橙色云海上几乎看不见——
HUD 的暖色在这片天空里是最低对比度的选择。改成冰白填充 + 琥珀辉光之后，
既保住了「琥珀 = 锁定/注意」的语义纪律，又在任何背景上都读得出来。

第二层是**区分**：打中机身、打中护盾节点、打出击坠，三种情况的声音、颜色与形状都不同。
护盾节点会弹开炮弹并给一圈冷色涟漪，这比任何血条都更快地告诉玩家「这个目标现在打不动」。

### 12.2 打击感的实现约束

- **反馈是 `age` 的纯函数**，不是 CSS 动画。模拟给事件盖章，HUD 换算成缩放与透明度。
  好处有三：暂停即冻结、掉帧不错位、reduced-motion 只需把缩放钉死。
- **效果有优先级预算**：同时存在的效果上限 190 个，超了先丢火花、再丢烟、再丢曳光弹，
  冲击波与爆炸最后丢。这样机炮扫射不会把一次击坠挤掉。
- **命中标记不朗读**。机炮一秒命中十几次，播报会淹没整个屏幕阅读器；
  只有击坠用 `role="log"` 播报。

### 12.3 战斗氛围

氛围的目标是让「只有你和三架敌机」看起来像「一场正在进行的战争」：

- **战场纵深**：前方 2.6–8.6 km 持续生成弹幕爆烟与曳光弹流，不参与任何判定，只画在天空里。
- **受创叙事**：血线低于 55% 的飞机开始拖烟，越低越黑越粗。这是纯渲染层的 30 个精灵池。
- **光照反应**：爆炸会点亮云层。用一盏常驻的 3 点池化 `PointLight`——
  常驻是因为增删光源会让 three.js 重编译材质，在空战中途造成卡顿。
- **调色跟随强度**：平静时明亮温暖，激战时压暗、起雾、变冷。用的是和配乐同一个 `intensity`。

### 12.4 取舍

- 配乐是**生成式**而不是音频文件：没有版权问题、没有下载、体积为零，
  但代价是不可能像录制的管弦乐那样有真实演奏的表情。这里用「写好的乐句 + 编曲规则」逼近：
  旋律是十句人写的乐句而不是随机音，所以它至少是**可唱的**。
- 打击反馈刻意做得比写实更响、更亮、更慢一点点。这是街机化表达，
  和飞行模型的选择一致：这个项目追求的是电影感，不是模拟器的克制。
- 编曲机只在小节线上换段，代价是「进入 boss」最多要等两小节（约 4 秒）。
  换来的是任何时候都不会听到半句被切断的旋律。
